# TV Energy Consumption Visualisation

An interactive data visualisation webpage built using **D3.js** to explore television energy consumption, star ratings, screen sizes, and screen technologies in Australia.

## Features
- **Interactive Histogram** – Displays annual TV energy consumption distribution.
- **Technology Filters** – Filter TVs by LED, LCD, and OLED.
- **Screen Size Filters** – Explore different TV screen sizes.
- **Interactive Scatterplot** – Visualises the relationship between star ratings and energy consumption.
- **Colour Coding** – Different colours represent LED, LCD, and OLED technologies.
- **Tooltips** – Hover over data points to view TV brand, model, and screen size.
- **D3 Transitions** – Smooth animations when filtering data.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- D3.js v7

## Dataset
Australian Government Energy Rating Data – Televisions (January 2025), containing 3,703 TV records.

## How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Right-click `index.html` and select **Open with Live Server**.
4. Explore the visualisations using the interactive filters and tooltips.
